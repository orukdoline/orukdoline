## About

### 안녕하세요! 웹개발자 진수우입니다.

평소 주변 사람들과 정보를 나누는 것에 흥미를 느꼈던 저는
하나의 서비스를 완성하기 위해 동료들과 지식과 경험을 공유하고
그렇게 만들어진 서비스를 통해 다양한 사람들이 정보를 나누는 웹 개발의 공유 문화에 매력을 느꼈습니다.<br/>
앞으로 많은 웹 개발에 참여함으로써 웹 개발의 공유 문화를 발전시켜나가는 개발자가 되고 싶습니다.
